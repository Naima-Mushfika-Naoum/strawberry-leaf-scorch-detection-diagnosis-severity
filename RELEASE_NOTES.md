# Research code and pretrained models

Includes three organized research notebooks, four pretrained artifacts, configurable paths, model checksums, paper citations, and data-request instructions. Curated images, annotations, and feature tables are not distributed.

Download `pretrained_models.zip` and extract at the repository root.

Validation covers notebook schema and syntax, archive integrity, file hashes and model metadata. Texture artifacts were loaded for inspection with cross-version warnings. Full neural-network loading, end-to-end inference, and reproduction of published metrics have not been verified. The code retains historical experimental variants documented in `docs/REVIEW_NOTES.md`.

Please cite: Mushfika, N., & Jaha, E. S. (2026). Semantic Analysis of Strawberry Leaf Scorch for Disease Detection, Symptom Diagnosis, and Severity Prediction. International Journal of Computational Intelligence Systems, 19, 368. https://doi.org/10.1007/s44196-026-01458-x
